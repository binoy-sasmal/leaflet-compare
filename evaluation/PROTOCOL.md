# Frozen evaluation protocol v1

Manifests were authored and hashed before comparison rules. Twelve cases per split; held-out uses distinct wording, a serif template and narrower text. Synthetic fictional decorative materials, never medication instructions. One seeded authoring change per changed case. The ambiguous case has an obscured quantity; its authoring label is still counted in detection recall.

A predicted finding matches one ground-truth change only when its category is exact and its normalized reference excerpt matches the affected reference paragraph (case and whitespace ignored). Insertions use revision text. Greedy one-to-one matching in finding order. This paragraph-level protocol measures localization/category, not exact character-span localization. Wrong category is both a miss and a false positive for critical metrics. Critical categories: quantity_unit, negation, warning, missing_paragraph. Wording is evaluated separately. All findings count in detection even when review is required; extraction issues do not count as change detections.

Report TP/FP/FN, precision and recall with denominators; null for zero denominators. Count all findings on unchanged/layout cases as false alarms. Break down detection by category and scan condition. Report case review routing and critical-change review coverage independently of detection. Review coverage means a reference paragraph overlaps a flagged finding or the whole case has an extraction issue; it is not detection. Report normalized character and word edit error rates against known full revision text, including synthetic header/footer, aggregated by total ground-truth characters/words. No confidence threshold is calibrated.

Held-out evaluation is run only after development tests and rules are settled. Record first-run result and any subsequent inspection/tuning in RUN_LOG.md. The generator reads labels; the application pipeline accepts only two PDFs and never imports evaluation code. File hashes detect accidental manifest edits, not malicious tampering.
